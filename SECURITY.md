# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by email:

**contact@otukenai.com**

Do not publish API keys, credentials, exploit details, personal data, or other sensitive material in a public GitHub issue.

Please include:

- the affected page or file;
- a clear description of the issue;
- reproducible steps, where possible;
- the potential impact;
- any safe remediation suggestion.

## Scope

The current production website at `https://otukenai.com/` and the files published from the `main` branch are in scope.

Only the current production version is supported.

## Safe research

Use non-destructive testing only. Do not attempt denial-of-service, social engineering, credential theft, persistence, data destruction, or access to data that is not your own.
